    a provisioner role that may CREATE DATABASE and CREATE ROLE (Secret {{ .Values.cluster.postgres.provisionerSecret.name }}), the

  - a ReadWriteMany volume for DATA_DIR (persistence.storageClass or persistence.existingClaim)

  - TLS certificates{{ if ne .Values.flavour "single" }} (wildcard *.{{ include "sendora.baseHost" . }}){{ end }}, DNS records, an ingress controller{{ if .Values.networkPolicy.enabled }}, a network-policy engine{{ end }}

1. Wait for the pods:
   kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w

2. One-time setup code (needed to create the first {{ if eq .Values.flavour "single" }}administrator{{ else }}platform administrator{{ end }}):
{{- if include "sendora.setupCodeEnabled" . }}
   kubectl -n {{ .Release.Namespace }} get secret {{ include "sendora.setupSecretName" . }} -o jsonpath='{.data.{{ .Values.setupCode.secretKey }}}' | base64 -d; echo
{{- else }}
   kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "sendora.fullname" . }} | grep -i "setup code"
{{- end }}

3. Open Sendora:
{{- if .Values.ingress.enabled }}
{{- if eq .Values.flavour "single" }}
{{- range .Values.ingress.hosts }}
   https://{{ . }}
{{- end }}
{{- else }}
   Platform console: https://admin.{{ include "sendora.baseHost" . }}   (tenants: https://<slug>.{{ include "sendora.baseHost" . }})
{{- end }}
{{- else }}
   No ingress. For a first look:
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ if eq .Values.flavour "cluster" }}{{ include "sendora.webName" . }}{{ else }}{{ include "sendora.fullname" . }}{{ end }} 8080:{{ .Values.service.port }}
{{- if ne .Values.flavour "single" }}
   then open http://admin.{{ .Values.baseDomain }} (the base domain must match what you open, for
   example baseDomain=localhost:8080 and http://admin.localhost:8080).
{{- else }}
   then open http://localhost:8080
{{- end }}
{{- end }}
{{- if ne .Values.flavour "single" }}

4. Create the first platform administrator on the console with the setup code, then create tenants
   (Platform console -> Tenants). Each tenant is served on <slug>.{{ .Values.baseDomain }}.
{{- else }}

4. Create the first administrator with the setup code.
{{- end }}
{{- if and (ne .Values.flavour "cluster") .Values.database.initialize }}

   helm upgrade {{ .Release.Name }} <chart> --reuse-values --set database.initialize=false
{{- end }}
